## Overview

A small browser-based application demonstrating Create, Read, Update and Delete operations for employee records.

## Features

- Add, list, edit and remove employee records.
- Manage name, role and salary.
- Modal-based editing and browser persistence using localStorage.

## Getting started

```bash
git clone https://github.com/Julioribeiroo/CRUD-em-JavaScript.git
cd CRUD-em-JavaScript
python -m http.server 8000
```

Open http://localhost:8000 in your browser (Python is only used to serve static files).

## Project structure

- `index.html` — interface and employee table.
- `style.css` — styling.
- `script.js` — CRUD logic and persistence.

## Example workflow

Open the application, add a fictional employee, edit their role or salary, then remove the record. Refresh the page to verify local persistence.

## Scope

This is a learning project, not a production employee database. Data is saved only in the browser; no server or authentication is implemented. Use fictional data only.
